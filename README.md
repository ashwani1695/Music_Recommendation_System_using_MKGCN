# Music Recommendation System

A graph-based music recommendation system using Graph Neural Networks (GNNs), Knowledge Graphs, and Multi-Modal Learning to generate personalized song recommendations.

## Features
- Personalized music recommendations  
- Graph-based user-item modeling  
- Knowledge graph embeddings  
- Multi-modal feature integration  
- Top-K recommendation generation  
- Cold-start problem handling  

## Tech Stack
- Python  
- PyTorch  
- Graph Neural Networks (GCN)  
- Knowledge Graphs  
- Pandas, NumPy  
- Scikit-learn  

## Project Workflow
- Data preprocessing and feature extraction  
- Knowledge graph construction  
- GNN-based recommendation modeling  
- Top-K recommendation generation  
- Model evaluation using ranking metrics
